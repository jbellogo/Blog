Mostly about computers 


1. You start with Nand logic gates which are esentially binary functions on binary strings. 
2. From logic gates, use combinational logic to build Elementary logic gates
3. From these gates, use combinational and sequential logic to build things like registers, RAM units and CPU. 
4. Then digital design and build a computer architecture, like the [[Hack Computer]]

We then introduce an assembler that can write machine code for this particular computer.
